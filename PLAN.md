# План Agent Telegram

Цель: отчёты агента и правки пользователя через одного Telegram-бота во время активной работы в Codex Desktop. [Краткие требования](docs/requests/2026-11-27-single-bot-plugin.md) содержат общие продуктовые решения.

## Реализованная основа

- Общий секрет и реестр проектов; режимы `single` и `parallel`.
- Один приёмщик, точные маршруты, отдельные очереди и состояния диалогов.
- Явная смена активного проекта и миграция совместимых старых настроек.
- Контрольные точки получения правок и подтверждение чтения из того же чата.
- Итоговый отчёт с предложением продолжить в ChatGPT.
- Локальный плагин Codex и распространение через GitHub по лицензии MIT.

## Текущий этап

1. Отделить устанавливаемые программы и инструкции от Git-истории, личных настроек и журналов разработки.
2. Проверить согласованность исходников и пакета 0.1.2, автономные тесты и отсутствие личных сведений в публичном содержимом.
3. Завершить короткую приёмку установленной копии: сообщение о начале → одна Telegram-правка → изменение тестового файла → квитанция → настоящий итог.
4. Отдельно подтвердить состояние доступной Git-истории и копий, которые сохраняет GitHub. Чистое дерево файлов не означает удаление всех старых копий.

Установка 0.1.1 через Desktop и живой single/parallel из рабочего клона уже описаны в [отчёте](docs/LOCAL_ACCEPTANCE_REPORT.md). Приёмку новой упаковки 0.1.2 нельзя считать пройденной по этим результатам.

Технические критерии — [план выпуска](docs/SINGLE_BOT_PLUGIN_PLAN.md). Для локальной проверки — [LOCAL_AUDIT.md](docs/LOCAL_AUDIT.md).
