# Agent Telegram

Отчёты кодового агента и ваши правки через одного Telegram-бота. Во время работы в локальном Codex агент отправляет этапы, вопросы и итог. На ближайшей проверке входящих он читает и учитывает ответ из Telegram.

| Как вы работаете | Куда писать |
| --- | --- |
| Один проект за раз (`single`) | В личку бота |
| Несколько проектов одновременно (`parallel`) | В тему проекта в одной Telegram-группе |

У каждого рабочего контекста свой хештег. В параллельном режиме у него также своя тема. Новый проект, ветка или роль используют того же бота.

## Установка в ChatGPT Desktop

Основная среда — локальный Codex в ChatGPT Desktop на macOS. Нужны Node.js 20+ и доступ к Telegram Bot API. Плагин распространяется через публичный GitHub.

1. Подключите каталог: `codex plugin marketplace add decorum-guy/agent-telegram`. Для локального клона вместо GitHub-адреса укажите абсолютный путь к корню репозитория.
2. В ChatGPT Desktop откройте **Плагины → источник Agent Telegram → Agent Telegram → Установить**. Если источник не появился, сохраните работу и перезапустите приложение.
3. Откройте новый локальный чат Codex в нужном проекте и напишите: **«Подключи этот проект через Agent Telegram»**.

Если `codex` отсутствует в PATH, в установленном Desktop можно использовать `/Applications/ChatGPT.app/Contents/Resources/codex-cli/bin/codex`.

Агент спросит, работаете ли вы над несколькими проектами одновременно. Для первой настройки создайте одного бота у [BotFather](https://t.me/BotFather) и сохраните токен в локальный файл. Для `parallel` добавьте этого бота администратором одной группы с темами и правом управления темами. Агент предложит имя и хештег проекта, а программа настройки создаст тему. Для следующего проекта токен заново не нужен.

[Обновление и удаление](docs/PUBLISHING.md) · [Миграция](docs/MIGRATION.md) · [Инструкция агенту](AGENT.md).

## Ежедневная работа

В личке отвечает один активный проект. В группе пишите в тему нужного проекта; хештег в своей теме необязателен. Переход на другой проект в `single` подтверждается одноразовой командой в личке, которая отделяет старую переписку от нового задания.

Агент проверяет входящие между действиями и перед итогом. Если он выполняет команду, правка может ждать следующей проверки. 👍 означает сохранение сообщения, 👀 — подтверждение чтения из чата агента. Применение видно в результате работы. После итогового отчёта откройте тот же чат в ChatGPT для продолжения.

Если чат закрыт после получения правки, но до подтверждения квитанции, возобновите его: правка остаётся за исходным чатом и подтверждается из той же рабочей папки.

Один компьютер принимает обновления общего бота. Настройки, очереди и секреты хранятся вне репозитория в `~/.agent-telegram`. Постоянный мост и CLI описаны [отдельно](docs/BRIDGE.md). Antigravity требует отдельной проверки.

## Проверки и версия

`node tests/run.mjs` запускает автономные проверки с имитацией Telegram и Codex. [Обезличенный отчёт о приёмке](docs/LOCAL_ACCEPTANCE_REPORT.md) отделяет живые результаты версии 0.1.1 от ещё не выполненной приёмки пакета 0.1.2. [Сценарий проверки](docs/LOCAL_AUDIT.md) описывает оставшийся обмен из установленной копии.

Установочный пакет 0.1.2 выделен в `plugins/agent-telegram`. Он содержит программы, инструкции и лицензию, без Git-истории, настроек пользователя и журналов разработки. Исходные файлы для разработки находятся в корне репозитория; порядок сборки — [в документации распространения](docs/PUBLISHING.md).
