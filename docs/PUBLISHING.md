# Распространение Agent Telegram через GitHub

Источник установки — этот публичный GitHub-репозиторий. Лицензия — [MIT](../LICENSE). Официальный каталог OpenAI не входит в процесс распространения. Основные шаги установки — [README](../README.md).

## Обновить установленный плагин

1. Подключите актуальный источник: `codex plugin marketplace add decorum-guy/agent-telegram`. Для уже зарегистрированного источника GitHub можно использовать `codex plugin marketplace upgrade agent-telegram`.
2. Откройте карточку **Плагины → Agent Telegram**, удалите прежнюю установку и установите из обновлённого источника. Затем откройте новый локальный чат. Этот путь подтвердил загрузку пакета 0.1.2 из нового GitHub-репозитория.
3. Проверьте фактическую версию и путь загруженного `SKILL.md`. Программы `tg*.mjs` лежат прямо в корне установленного пакета. Справка `node <корень-плагина>/tg-listen.mjs --help` должна содержать `--checkpoint` и `--received`. Номер в карточке каталога сам по себе не доказывает обновление исполняемых файлов.
4. Убедитесь, что установленная папка не содержит `.git`, исходной переписки или личных настроек. Проведите согласованный короткий обмен в нужном проекте.

Общий бот, настройки и очереди находятся отдельно в `~/.agent-telegram`; их не нужно удалять при переустановке плагина.

## Копии, полученные до очистки истории

Старые клоны и кэш 0.1.1 могут содержать прежнюю историю даже после обновления удалённого репозитория. Получите новый клон после завершения очистки. Не сливайте старую историю с новой и не отправляйте старые ветки обратно.

Для установленного плагина используйте штатное удаление плагина и источника перед новой установкой. Если старая копия остаётся на диске, удаляйте только проверенный каталог Agent Telegram после остановки связанных процессов. Не удаляйте общие каталоги Codex, настройки других плагинов или `~/.agent-telegram`. Локальные резервные копии и журналы обрабатываются владельцем отдельно и не загружаются в GitHub.

Переписанные ветки не очищают автоматически read-only ссылки PR, кэш GitHub и ранее скачанные копии. Состояние каждого из этих мест проверяется отдельно. Порядок работы с копиями провайдера описан в [документации GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).

## Сборка пакета

```sh
node scripts/build-plugin.mjs
node scripts/build-plugin.mjs --check
node tests/run.mjs
```

Marketplace указывает на `plugins/agent-telegram`. Сборка использует явный список программ, манифестов, skill, необходимых инструкций и лицензии. Не добавляйте весь корень репозитория или пользовательские файлы. Согласованность исходников и копии пакета проверяется отдельно от живого обмена с Telegram.

## Удалить

Откройте **Плагины → Agent Telegram → Удалить**. Удаление источника: `codex plugin marketplace remove agent-telegram`. Если включали постоянный мост, сначала остановите и удалите свою интеграцию по [инструкции](BRIDGE.md). Локальная конфигурация, история и токен сохраняются отдельно для будущего подключения.

## Сеть Telegram

Для прямого подключения нужен доступ к `api.telegram.org`. Если требуется доверенный HTTP-прокси, поддерживающая его версия Node может использовать `HTTPS_PROXY` и `NODE_USE_ENV_PROXY=1` в окружении процесса. Возможности установленной версии проверьте по [документации Node](https://nodejs.org/learn/http/enterprise-network-configuration). Параметры прокси и учётные данные не коммить.

[Формат плагина и команды каталога](https://developers.openai.com/plugins/build/plugins).
