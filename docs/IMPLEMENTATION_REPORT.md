# Реализация Agent Telegram

Это обезличенное описание архитектуры. Факты живой приёмки и их пределы приведены отдельно в [LOCAL_ACCEPTANCE_REPORT.md](LOCAL_ACCEPTANCE_REPORT.md).

## Общая схема

| Компонент | Поведение |
| --- | --- |
| Бот и владелец | Одна общая настройка на установку |
| `single` | Личка и один явно активированный проект |
| `parallel` | Одна форумная группа, темы и хештеги проектов |
| Приём | Один poller, отдельные очереди проектов |
| Активный чат | `--checkpoint` и явный `--received` из того же контекста |
| Итог | `--final` добавляет завершение и переход в ChatGPT |
| Распространение | Локальный плагин из GitHub, MIT |

Общий транспорт хранится вне Git: `~/.agent-telegram/projects.json`, секрет и offset. Состояние постоянного моста разделено по проектам. Совместимая миграция сохраняет очереди и историю; разные токены не объединяются автоматически.

## Сохранность правок

Маршрут проверяет владельца, чат, тему, хештег и ответ. Конфликт не разрешается рассылкой нескольким проектам. В `parallel` личка не является запасным адресом.

Смена активного `single`-проекта требует одноразового подтверждения. Старые входящие остаются прежнему адресату; если он неизвестен, сообщения сохраняются отдельно без исполнения.

Контрольная точка сохраняется до вывода для модели. Пока чат не подтвердил квитанцию, она переживает перезапуск и принадлежит исходному чату и рабочей папке. Подтверждение чтения отделено от применения. Возобновление другого чата не забирает непрочитанную правку.

## Упаковка 0.1.2

Разработческие исходники находятся в корне репозитория. Каталог установки использует отдельную папку `plugins/agent-telegram`, собранную из явного списка файлов. Пакет не должен включать Git-историю, проектные настройки, сырые отчёты или переписку.

Манифесты и программы этой упаковки требуют собственной проверки установленной копии. Приёмка 0.1.1 не объявляется приёмкой 0.1.2.

## Проверенные предыдущие результаты

Для версии 0.1.1 локальные автономные прогоны показали 185 успешных проверок. Рабочий клон прошёл живые single/parallel-сценарии; установка из GitHub через Desktop и совпадение файлов установленной 0.1.1 подтверждены. В коротком обмене из установленной копии входящее слово не поступило, поэтому чтение, применение, квитанция и реальный итог в этом проходе остались BLOCKED.

Сведения о прежних версиях являются историческими результатами локального аудитора. Новые проверки следует записывать отдельно с версией, средой и наблюдаемым основанием.

## Границы

Один компьютер принимает обновления бота. Сон компьютера, отсутствие сети и остановленный runtime ограничивают доставку. Постоянный мост и Antigravity не входят в подтверждённый основной живой сценарий. Чистая папка пакета не подтверждает удаление старых GitHub-ссылок, кэшей и ранее скачанных копий.
