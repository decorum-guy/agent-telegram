# Обезличенный отчёт о локальной приёмке

Источник: опубликованные результаты локального аудитора и подтверждение пользователя. Здесь сохранены технические результаты версии **0.1.1**, без личных путей, идентификаторов диалогов, текста переписки и ссылок на удаляемую историю. Эти сведения не являются новой живой проверкой упаковки **0.1.2**.

## Автономные проверки 0.1.1

По отчёту аудитора на macOS успешно прошли **185 из 185** проверок под Node.js 20, 24 и 26. CI на Linux с Node 20 и 24 также завершился успешно. Структура манифестов, пути skill и запуск справки программ вне рабочего репозитория проверены.

Тесты используют имитации Telegram и runtime. Параллельный запуск двух полных наборов в одном окружении создавал конфликт тестового порта; последовательные прогоны завершились успешно.

## Живые сценарии из рабочего клона 0.1.1

Использовались два видимых тестовых чата Desktop с Luna / Low, один согласованный бот и отдельные рабочие папки.

| Сценарий | Наблюдаемый результат |
| --- | --- |
| `single` | Модель получила слово только через Telegram, изменила тестовый файл и подтвердила чтение в том же активном ходе |
| Переключение проекта | Второй проект подключён к тому же боту после одноразового подтверждения |
| `parallel` | Настройка создала две темы; каждый чат применил только свою правку |
| Конфликт маршрута | Хештег другого проекта в закреплённой теме был отклонён |
| Повторный запуск | До ACK возвращалась та же квитанция; после ACK повтор отсутствовал |
| Завершение | Отправлен настоящий итог с хештегом, результатом и приглашением вернуться в ChatGPT |

В этих опытах время от метки Telegram до вывода для модели составляло **0,3–2,0 секунды** при уже запущенной проверке. Метка Telegram имеет точность до секунды. Между проверками задержка зависит от выполняемой задачи; это не гарантия постоянной доставки за такой интервал.

## Установка 0.1.1 из GitHub через Desktop

После удаления и повторной установки через интерфейс новый видимый чат загрузил skill из установленной 0.1.1. Аудитор сопоставил SHA-256 skill, манифестов и пяти программ с кандидатом GitHub. Справка установленного `tg-listen.mjs` содержит `--checkpoint` и `--received`.

В установленный пакет также попала папка `.git` с прежней историей. Это дефект границы пакета 0.1.1, который послужил основанием для отдельной папки установки в 0.1.2.

Установленная копия отправила сообщение о начале в согласованную тему. Во время восьми окон ожидания подходящее слово не поступило. Поэтому изменение файла, подтверждение квитанции и настоящий итог в этом проходе остаются **BLOCKED**. Формат `--final` и приглашение вернуться в ChatGPT проверены через `--dry-run`.

Тестовый чат архивирован. По отчёту аудитора тестовые процессы освободили блокировки, временные копии токена и настроек удалены. Постоянный мост для этой проверки не устанавливался.
