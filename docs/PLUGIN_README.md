# Agent Telegram

Отчёты агента и правки пользователя через одного Telegram-бота во время активной работы в локальном Codex.

- `single`: один активный проект в личке бота.
- `parallel`: тот же бот, одна группа с темами, свой хештег и тема каждого рабочего контекста.

В новом чате попросите: **«Подключи этот проект через Agent Telegram»**. Агент уточнит режим, использует существующую настройку и поможет один раз подключить бота. Токен сохраняется в локальный файл вне Git и переписки. При нужных правах настройка сама создаёт тему проекта.

Агент проверяет входящие между действиями и перед завершением. 👍 означает сохранение сообщения, 👀 — подтверждение чтения. Применение подтверждается результатом работы. После итогового отчёта вернитесь в тот же чат ChatGPT для продолжения.

Программы `tg*.mjs` находятся прямо в корне этого установленного пакета. Инструкции подключения — `AGENT.md`; миграции — `docs/MIGRATION.md`; дополнительного постоянного моста — `docs/BRIDGE.md`. Корень пакета расположен на два уровня выше `skills/agent-telegram/SKILL.md`. Запускайте Node с абсолютным путём программы из рабочей папки своего проекта.

Нужны Node.js 20+ и доступ к Telegram Bot API. Основная среда — локальный Codex в ChatGPT Desktop на macOS. Один компьютер принимает обновления общего бота; настройки и секреты остаются в `~/.agent-telegram`.
