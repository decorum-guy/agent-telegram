# Требования к первому выпуску

Этот документ содержит обезличенные требования к продукту. Исходная личная переписка в публичной документации не сохраняется.

Agent Telegram решает две задачи: отчёты агента о ходе работы и получение правок пользователя из Telegram во время активного чата.

- Всегда один Telegram-бот для всех проектов пользователя.
- При первом подключении агент выясняет, ведётся ли параллельная работа.
- `single`: личка одного бота и один активный проект, без обязательной группы.
- `parallel`: тот же бот и одна группа с темами; отдельная тема и уникальный хештег рабочего контекста. Имя и хештег предлагает агент, тему создаёт программа настройки.
- Сохраняется связь рабочего контекста/ветки/роли, проекта и хештега. Между проектами не смешиваются сообщения и подтверждения.
- Основной клиент — локальный Codex в ChatGPT Desktop. CLI и постоянный мост — дополнительные способы работы; Antigravity проверяется отдельно.
- В финале агент сообщает результат и завершение, предлагает продолжить в том же чате ChatGPT.
- Распространение — через публичный GitHub по MIT. Официальный каталог OpenAI не требуется.
- Пакет и публичный репозиторий не должны содержать личную переписку, данные установок или секреты. Очистка текущего дерева и старых Git-копий проверяется раздельно.
