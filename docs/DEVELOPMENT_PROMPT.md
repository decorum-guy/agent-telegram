# Задание следующему разработчику

Прочитай [AGENTS.md](../AGENTS.md), [PLAN.md](../PLAN.md) и [краткие требования](requests/2026-11-27-single-bot-plugin.md). Получи актуальное состояние репозитория и отдельно зафиксируй проверяемую версию.

Сохраняй одного Telegram-бота: `single` через личку, `parallel` через одну группу с темами. У проектов отдельные хештеги, очереди и подтверждения точных диалогов. Основной сценарий работает во время активного хода Desktop.

Пакет собирается из явного списка файлов в `plugins/agent-telegram`. После изменения его исходников пересобери пакет и проверь отсутствие Git-истории и личных данных. Не восстанавливай прежние журналы, исходную переписку или старые ветки из локального клона.

При аудите используй [LOCAL_AUDIT.md](LOCAL_AUDIT.md). Не повторяй всю историческую матрицу без причины: проверяй конкретный оставшийся риск, реальные файлы установленной копии и согласованный обмен. Исправляй воспроизводимые ошибки и отмечай пределы проверки.

Распространение через GitHub по MIT описано в [PUBLISHING.md](PUBLISHING.md). Официальный каталог OpenAI не входит в задачу.
