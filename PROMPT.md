# Короткое подключение агенту

После установки плагина достаточно попросить: «Используй Agent Telegram для отчётов и правок в этом проекте». При первом подключении агент уточнит режим, а существующие настройки переиспользует.

Если плагин ещё не установлен, добавьте к заданию этот блок:

```text
Подключи этот проект к agent-telegram: https://github.com/decorum-guy/agent-telegram. Прочитай AGENT.md выбранной версии. При необходимости клонируй набор в ~/.agent-telegram/kit, вне репозитория моего проекта. Начни с раздела «Рабочий ход Codex».
Нужны отчёты и мои правки через одного общего Telegram-бота. Если режим неизвестен, спроси: работаю ли я над одним проектом за раз или над несколькими параллельно. Для single используй личку; для parallel — одну группу с темами. Сохрани связь рабочий контекст/ветка/роль → проект → хештег. Нового бота для каждого проекта не создавай. Токен сохраняется локально, не проси его в чате.
Отправляй существенные отчёты, читай входящие между действиями и перед итогом. Подтверждай правки штатной квитанцией из этого чата. В конце отправь итог через --final и предложи продолжить работу в этом чате ChatGPT. Постоянный мост подключай только как отдельно согласованную возможность. Разделяй выполненное, реально проверенное и непроверенное; соблюдай разрешения и правила проекта.
```

Установка из GitHub — [README.md](README.md). Используйте актуальный источник после очистки истории; прежний клон не следует сливать с новой историей.
